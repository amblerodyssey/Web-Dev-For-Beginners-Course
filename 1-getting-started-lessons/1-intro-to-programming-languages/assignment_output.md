- R
    - statistical computing, data analysis and graphics. Developed in U of Auckland in 1990s
    - developed on top of S language, R, generally an interpreted langauge, provides a wide variety of statistical and graphing techniques that is highly extensive via packages (e.g. function sets, data, compiled code), resulting in ease of producing plots, matrices opeartions, use of mathematical symbols and formulae.
- Swift
    - programming language specific for all Apple platforms
    - released in 2014 by Apple and later maintined by open-source community, Swift is a complied language serves to create a high-level, general-purpose development environment that modernises syntax and safety without sacrificing speed.  
- Go (Golang)
    - general purpose programming language often used for cloud-based services
    - designed at Google in 2007, Go is a complied language known for its simplicity of syntax and efficiency of development. by combining run-time efficiency like C and readiability like Python, this is ideal for cloud-native development from greater developer productivity and greater cloud compute efficiencies/cost savings
